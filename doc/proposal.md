# 你画我猜 AI — 需求文档 V1

## 1. 产品定义

一个网页游戏：系统随机出题 → 用户在 Canvas 上画图 → AI 猜测用户画的内容 → 用户判断 AI 猜得对不对 → 计分并进入下一轮。

## 2. 用户故事

1. 用户打开页面，看到空画板和顶部显示的**当前题目**
2. 用户使用画笔在画板上画图
3. 用户点击"提交猜画"
4. AI 返回猜测结果，页面展示 AI 猜的是什么
5. 用户点击 ✅ 猜对了 或 ❌ 猜错了
6. 系统判定结果并更新分数
7. 用户点击"下一轮"，画板清空，新题目出现

## 3. 核心规则

| 规则项 | 决策 | 备注 |
|--------|------|------|
| 出题方式 | 系统随机出题 | 100% 后端控制，与 AI 无关 |
| 题目词库 | 后端内置固定词库 | AI 生成约 50-100 个常见中文名词，写死在代码中 |
| 计分规则 | 初始 0 分，猜对 +1，猜错 +0 | 无上下限 |
| 回合流转 | 用户手动点击"下一轮" | 点击后自动清空画板、更换题目 |
| 用户判断 | ✅ 猜对了 / ❌ 猜错了 | 二元判断 |

## 4. 画板功能

| 功能 | V1 | 说明 |
|------|-----|------|
| 画笔 | ✅ | 单色（黑色），固定粗细 |
| 橡皮擦 | ✅ | 擦除局部 |
| 清空 | ✅ | 一键清除整个画板 |
| 撤销 | ❌ | V2 考虑 |
| 多色/粗细调节 | ❌ | V2 考虑 |
| 形状工具 | ❌ | 不在规划内 |
| 移动端触摸 | ❌ | 仅桌面鼠标 |

## 5. AI 模型对接

| 项目 | 值 |
|------|-----|
| V1 Provider | DeepSeek（唯一） |
| API 地址 | `https://api.deepseek.com` |
| 模型名称 | `deepseek-v4-pro` |
| 认证方式 | API Key（环境变量 `DEEPSEEK_API_KEY`） |
| 超时 | 5 秒 |
| 置信度阈值 | 0.65（低于此值视为降级） |
| 架构预留 | PredictorProtocol + ModelRegistry 保留多 Provider 扩展能力 |

> V1 仅接入 DeepSeek，Gemini/OpenAI/Qwen 的 Provider 文件暂为空壳，不实现。

## 6. 数据持久化

| 表/数据 | 字段 | 用途 |
|---------|------|------|
| 回合记录 | id, topic(题目), guess(AI猜测), is_correct(是否正确), model_name, created_at | 历史追溯 |

> V1 仅此一张表，SQLite 存储。

## 7. 计分逻辑

- 用户判断 ✅ 猜对了 → 系统对比 AI 的 `guess` 与后端存储的当前 `topic`：
  - 若 AI 真猜对了（语义匹配）→ 用户判断正确 → **+1 分**
  - 若 AI 猜错了 → 用户判断错误 **或** 用户判断正确（即用户认为 AI 猜对了但实际不对）→ +0 分，但记录用户判断
- 用户判断 ❌ 猜错了 → 系统同样对比：
  - 若 AI 真猜对了 → +0 分（用户判断失误）
  - 若 AI 猜错了 → +0 分（用户判断正确，但猜错不得分）

> 简化理解：**只有当"AI 猜对题目"且"用户确认 ✅"时，才 +1 分。其余情况均 +0。**

## 8. 用户交互流程（完整）

```
[y] 页面加载
[y] 显示随机题目（如"请画：苹果"）
[y] 用户在画板上画图
[y] 用户点击"提交猜画"
[y] 前端导出 Canvas 为 base64 → POST /api/guess
[y] 后端转发给 DeepSeek → 等待最多 5 秒
[y] 前端显示加载动画（推断中…）
[y] AI 返回结果 → 前端展示猜测内容（如"AI 猜：苹果"）
[y] 用户点击 ✅ 或 ❌
[y] 系统计分并更新显示
[y] 用户点击"下一轮" → 画板清空 → 新题目 → 回到步骤 2
```

## 9. 页面布局（4 区结构）

```
┌─────────────────────────────────────────┐
│  题目区  │  "请画：苹果"  │  得分：3      │
├─────────────────────────────────────────┤
│                                         │
│           Canvas 绘制区                  │
│          (固定 500×400)                  │
│                                         │
├─────────────────────────────────────────┤
│  [清空] [橡皮擦] [提交猜画] [下一轮]       │
├─────────────────────────────────────────┤
│  AI 结果展示 / 推断中…                   │
│  [✅ 猜对了]  [❌ 猜错了]                │
└─────────────────────────────────────────┘
```

## 10. API 端点

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/topic` | 获取当前题目（随机抽取） |
| POST | `/api/guess` | 提交图片，AI 猜测 |
| POST | `/api/feedback` | 用户反馈（对/错） |
| GET | `/api/score` | 获取当前分数 |

## 11. 技术边界

| 约束 | 值 |
|------|-----|
| 图片大小上限 | 2MB |
| 图片格式 | PNG |
| AI 超时 | 5 秒 |
| 前端框架 | Vite + TypeScript + Canvas API |
| 后端框架 | FastAPI + Pydantic V2 |
| 数据库 | SQLite |
| 包管理 | uv（pyproject.toml） |

## 12. 非功能需求

- 页面加载后题目立即可见（无需等待 AI）
- AI 调用超时后显示降级提示，不阻塞页面
- 画板支持鼠标拖拽绘制
- 响应式布局，居中显示
